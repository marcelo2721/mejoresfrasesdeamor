## 🔗 INTERNAL LINKING STRATEGY (HUB-SPOKE)

### Patrón de Linking:

**Desde HOMEPAGE:**
- Link a "Frases de Amor" (HUB) con anchor "las mejores frases de amor"

**Desde HUB "Frases de Amor":**
- Links a todas las 7 sub-páginas FASE 1
  - "Frases cortas" con anchor "frases cortas"
  - "Frases bonitas" con anchor "frases bonitas"
  - "Para dedicar" con anchor "frases para dedicar"
  - etc.

**Desde cada SUB-PÁGINA:**
- Link arriba: Vuelve al HUB
- Links laterales: A otras sub-páginas relacionadas
  - "Frases cortas" → "Frases bonitas"
  - "Amor profundo" → "Cartas de amor"
  - "Novia" → "Novio"

**Beneficio:**
- Poder se concentra en HUB
- Cada sub-página refuerza el HUB
- Topical authority: "Frases de Amor" se vuelve indispensable
- CTR mejorado: Usuarios navegan entre artículos relacionados

## 📝 ESTRUCTURA DE CADA ARTÍCULO

### Formato Estándar (1,500-2,000 palabras):

1. **Intro (150w)** - Contexto + keyword natural
2. **Frases principales (7-10 frases)**
   - Cada una: 150-200 palabras de análisis
   - Contexto: cuándo usarla, cómo aplicarla
   - Sentimiento: qué evoca, por qué funciona
3. **Sección Psicológica (200w)**
   - Neuroquímica del amor
   - Investigación científica
   - E-E-A-T signals
4. **Sección Práctica (150w)**
   - Cómo decirla efectivamente
   - Contextos de uso
   - Personalizaciones
5. **FAQ Schema (6-8 preguntas)**
   - "¿Cuál es la frase más romántica?"
   - "¿Cómo sé cuál usar?"
   - "¿Funcionan realmente?"
6. **Related Content (CTAs)**
   - Links internos a artículos relacionados
7. **Author Byline**
   - Credibilidad + E-E-A-T

**Total:** 1,500-2,000 palabras
**Schema:** Article + FAQ + BreadcrumbList
**AdSense:** 3 espacios (leaderboard + 2 rectangles)
