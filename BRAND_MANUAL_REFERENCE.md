## Estructura a Adoptar

### 1. Paleta de colores
- Colores de marca (3-4 principales)
- Neutros (texto, fondos, bordes)
- Semánticos (error, success)
- Tabla de contraste WCAG

### 2. Tipografía
- Familias de fuente (display + body)
- Escala tipográfica con peso, tamaño, line-height
- Reglas de letter-spacing y text-transform
- Uso de cada nivel

### 3. Espaciado
- Tokens gap-xs a gap-2xl (múltiplos de 4px)
- Layout padding
- Modal padding
- Tabla con valor y uso

### 4. Border Radius
- sm, md, lg, pill, circle
- Asimétricos si aplica

### 5. Componentes
- Botones (variantes + tamaños)
- Inputs / Formularios
- Chips / Badges / Avatares
- Cards (adaptadas a frases, no vendedores)
- Alertas / Notificaciones
- Componentes específicos del sitio

### 6. UX Patterns
- Tabla con patrón, descripción, propósito
- Ejemplos reales de uso

### 7. Tono y Voz
- Principios clave
- Qué NO hacer
- Ejemplos de copy

### 8. Token Sheet (CSS)
- Todas las variables documentadas

## Adaptación para Mejores Frases de Amor

**Cambios principales:**
- Paleta: Rosa/rojo romántico en lugar de teal
- Tipografía: Serif elegante (Playfair) + sans limpio (Inter/Poppins)
- Componentes: Quote cards, article hero, share CTAs
- Patrones: Hero + search → Hero + "Leer artículos" CTA
- Copy: Frases de amor, no bodas
